# Example presets

[Italiano](README.it.md)

| File | Layout |
| --- | --- |
| cinema.json | One display, tracking off |
| dual-coding.json | Two displays, tracking on |
| triple-coding.json | Three displays, tracking on |

These complete settings files match the current Codable schema. They are starting points, not performance recommendations. Prefer the app presets in normal use; no import button exists. To try a JSON file, quit the app, back up your existing `~/Library/Application Support/RayNeoWorkspace-Dev/settings.json`, copy the example there and reopen. Create the directory if missing. Restore the backup to undo. Do not edit while the app runs. All keys are required by the current decoder. Background image paths are empty. Language and Liquid Glass are separate UserDefaults preferences. Turn tracking off for other headset experiments.
