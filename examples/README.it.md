# Preset di esempio

[English](README.md)

| File | Layout |
| --- | --- |
| cinema.json | Uno schermo, tracking spento |
| dual-coding.json | Due schermi, tracking acceso |
| triple-coding.json | Tre schermi, tracking acceso |

I JSON completi rispettano lo schema Codable corrente. Sono punti di partenza, non raccomandazioni di prestazioni. Per uso normale preferisci i preset nell'app; non c'è importazione file. Per provare un JSON chiudi l'app, salva una copia di `~/Library/Application Support/RayNeoWorkspace-Dev/settings.json`, copia l'esempio in quella posizione e riapri. Crea la directory se manca. Ripristina la copia per annullare. Non modificare il file con app aperta. Tutte le chiavi sono richieste dal decoder. I percorsi immagine sono vuoti. Lingua e Liquid Glass sono preferenze UserDefaults separate. Disattiva il tracking negli esperimenti con altri visori.
