# Sicurezza

[English](SECURITY.md)

Preview sperimentale senza audit indipendente. Consulta [permessi e privacy](docs/it/privacy.md). Non pubblicare codici di abbinamento, chiavi o contenuti personali. Per vulnerabilità usa la segnalazione privata GitHub se abilitata; altrimenti apri una issue minima chiedendo un contatto privato, senza dettagli di exploit o dati sensibili. Nessuna email di sicurezza monitorata è configurata.
