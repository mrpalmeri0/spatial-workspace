# Changelog

## 0.11.0 — development preview

- Native SwiftUI/AppKit Mac dashboard, optional Liquid Glass, adaptive controls and live workspace preview.
- One/two/three-display presets with appearance and layout controls.
- Cursor recall, radar, Focus lock and a non-activating quick panel with keyboard.
- Window restoration within the running process.
- Experimental iPhone/iPad companion, TLS/PSK host, H.264 video, manual monitor selection and external-display scene.
- Gyro bias correction update; real-device slow-motion and long-session tests remain necessary.
- Developer ID/notarization tooling, separate from source publication.
- Updated English/Italian documentation, explicit device matrix, usage examples and complete source packaging.

Current hardware acceptance and remote network/video verification remain pending. See docs/GITHUB_PUBLICATION.md for checks performed during repository preparation.

## 0.10.1 — historical baseline

Earlier project documentation reports fixes for startup, three-screen viewing, head tracking and reopening controls from the Dock. This does not certify the current native UI or companion.
