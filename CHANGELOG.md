# Changelog

[Italiano](CHANGELOG.it.md)

## 0.11.0 · development preview

- Public names Spatial Workspace / Spatial Remote.
- Native SwiftUI/AppKit Mac UI, optional Liquid Glass and English/Italian localization.
- 1–3 display presets, 3D/live preview, Focus, radar, cursor recall and keyboard panel.
- Window recovery limited to the running process.
- Experimental TLS/PSK and H.264 iPhone/iPad remote with external scene.
- Bilingual guides, real interface screenshots, JSON presets and complete source package.

Full device acceptance, remote roundtrip and tracking for other headsets remain pending.
